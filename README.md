# Prism-Survivor-project — 똥 피하기

60초 동안 떨어지는 똥을 피하며 버티는 픽셀 아트 미니게임입니다.

- 갈색 똥(장애물)에 맞으면 체력이 1 감소, 컬러 똥(회복 아이템)을 먹으면 체력이 1 증가 (최대 5)
- 체력이 0이 되면 게임 오버, 60초를 버티면 승리
- 배경음악과 효과음(장애물: "드헉!", 회복: "예~")은 브라우저에서 직접 합성되며 외부 음원 파일을 쓰지 않습니다
- **명예의 전당**: 닉네임과 함께 등록되는 순위표로, 서버(`/api/leaderboard`)에 저장되어 **모든 방문자가 같은 순위표를 공유**합니다 (1/2/3등은 금·은·동으로 표시, 내 순위가 10위 밖이면 화면 하단에 빨간 테두리로 항상 고정 표시됩니다)

## 로컬 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

## 배포 (Render)

이 저장소에는 `render.yaml`이 포함되어 있어 Render의 **Blueprint** 기능으로 바로 배포할 수 있습니다.

1. [Render 대시보드](https://dashboard.render.com)에서 **New +** → **Blueprint** 선택
2. 이 GitHub 저장소(`Prism-Survivor-project`) 연결
3. 자동으로 감지된 설정 그대로 **Apply** 클릭
4. 배포가 끝나면 Render가 제공하는 `https://xxxx.onrender.com` 링크로 접속

무료 플랜은 일정 시간 방치되면 서버가 잠들었다가 다음 요청 시 다시 깨어나며(첫 요청이 몇십 초 느릴 수 있음), 이때 로컬 파일(`data/leaderboard.json`)에 저장된 순위표가 초기화될 수 있습니다. 순위표를 완전히 안전하게 유지하려면 이후 별도의 데이터베이스 연동이 필요합니다.
